خطوات تحويل حاسبة الزيتون إلى تطبيق APK
==========================================

محتويات الحزمة (ارفعها كلها معاً بدون تغيير أسمائها):
  index.html            الصفحة
  manifest.json         بيانات التطبيق (الاسم، الألوان، الأيقونات)
  sw.js                 يجعل التطبيق يعمل بدون إنترنت
  icon-*.png            أيقونات التطبيق (4 ملفات)


المرحلة 1: رفع الملفات على GitHub Pages (مجاني، مرة واحدة)
---------------------------------------------------------
1. افتح github.com وأنشئ حساباً (أو سجّل دخولك).
2. اضغط زر + ثم New repository.
   - الاسم: olive-calc
   - اختر Public
   - اضغط Create repository
3. داخل المستودع اضغط: uploading an existing file
   اسحب الملفات السبعة كلها (بدون ملف "اقرأني" هذا) ثم اضغط Commit changes.
4. اذهب إلى Settings ثم Pages من القائمة الجانبية:
   - Source: Deploy from a branch
   - Branch: main  /  (root)  ثم Save
5. انتظر دقيقة أو دقيقتين، وسيظهر رابطك بهذا الشكل:
   https://اسم-حسابك.github.io/olive-calc/
   افتحه من الجوال وتأكد أن الحاسبة تعمل.


المرحلة 2: بناء ملف APK من PWABuilder
------------------------------------
1. افتح pwabuilder.com
2. الصق رابط GitHub Pages واضغط Start.
3. سيفحص الموقع الصفحة، ويُفترض أن يُظهر أن الـ Manifest والـ Service Worker سليمان.
4. اضغط Package For Stores ثم اختر Android ثم Generate Package.
   - Package ID: اتركه كما هو أو اكتب مثلاً  com.mahdi.olivecalc
   - App name: حاسبة الزيتون
5. سيُنزّل ملف ZIP يحتوي على:
   - ملف .apk    للتثبيت المباشر على الجوال
   - ملف .aab    للرفع على Google Play (إن أردت لاحقاً)
   - ملف signing.keystore وملف signing-key-info.txt
   مهم جداً: احتفظ بملفَي التوقيع في مكان آمن، فبدونهما لا تستطيع
   إصدار تحديث للتطبيق نفسه على Google Play.


المرحلة 3: التثبيت على الجوال
-----------------------------
1. انقل ملف .apk إلى الجوال (واتساب لنفسك، أو Drive، أو كابل).
2. افتحه، وإذا طلب الجوال السماح بـ "تثبيت تطبيقات من مصادر غير معروفة" فوافق.
3. أول تشغيل يحتاج إنترنت مرة واحدة لتحميل الملفات، وبعدها يعمل بدون إنترنت.

ملاحظة: إذا ظهر شريط عنوان المتصفح أعلى التطبيق، فهذا يعني أن ملف
assetlinks.json لم يُضف. التطبيق يعمل طبيعياً، ولإخفاء الشريط ارفع ملف
assetlinks.json الذي يعطيك إياه PWABuilder داخل مجلد اسمه .well-known
(هذه الخطوة تحتاج مستودعاً باسم  اسم-حسابك.github.io ، ويمكنني مساعدتك فيها).


التحديثات لاحقاً
----------------
- عدّل index.html وارفعه على GitHub مكان القديم.
- غيّر في sw.js السطر:  olive-calc-v1  إلى  olive-calc-v2  (ثم v3 ... وهكذا).
- التطبيق المثبّت يأخذ التحديث تلقائياً عند فتحه مع وجود إنترنت، بدون بناء APK جديد.


ما الجديد في الصفحة
-------------------
- تحفظ آخر القيم المدخلة (السعر، السعة، العملة...) وتبقى عند إعادة فتح التطبيق.
- زر نسخ التقرير يعمل بطريقة أحدث وأكثر توافقاً داخل التطبيق.
- تعمل بدون إنترنت بالكامل بعد أول فتح.
